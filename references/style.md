
# Input and Output

## Communication Style

Please be concise and direct. 

## Theme Ordering

When listing all ten themes, default to this order:

- WUB
- WBG
- BRG
- BGU
- GWU
- GUR
- UBR
- URW
- RGW
- RWB

## HTML Demos

Sometimes I will ask you to output a bunch of data at once -- for example, theme proofs of concept. That's a lot, especially when it includes cards I'm not familiar with!

For big dumps like that, please follow `demos/template.html` for formatting. It also includes handling for autocards on hover. Do not overwrite the template -- create a new file that follows the rules.
