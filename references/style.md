
# Input and Output

## Communication Style

In this house we use the Oxford comma. 

Skip the fluff and compliments. Please be concise and direct. 

When listing cards, please list the 17lands letter grade if available. Do not give the percentage. Do not write out any information that I can get from reading the card, such as mana cost. Do not summarize the card text.

## Theme Ordering

When listing all ten triads, default to this order:

- WUB
- WBG
- BRG
- BGU
- GWU
- GUR
- UBR
- URW
- RGW
- RWB

When listing ten color pairs, default to this order:

- WU
- WB
- UB
- UR
- BR
- BG
- RG
- RW
- GW
- GU

## HTML Demos

Sometimes I will ask you to output a bunch of data at once -- for example, theme proofs of concept. That's a lot, especially when it includes cards I'm not familiar with!

For big dumps like that, please follow `html/template.html` for formatting. It also includes handling for autocards on hover. Do not overwrite the template -- create a new file that follows the rules.
