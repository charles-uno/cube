
# Themes

Limited environments typically have themes to steer drafting and deck construction. Players often want to pick a strong payoff early, which rewards them for playing into a certain theme. Enablers are typically lower picks. 

For example, a drafter may spend an early pick on [[Kargan Warleader]]. It's a payoff that rewards you for playing a bunch of warriors. They would later try to draft enablers such as [[Tyrox, Saurid Tyrant]] (which is a warrior) and [[Dalkovan Packbeasts]] (which creates warrior tokens). 

Themes in a cube are "fuzzier" than in ordinary draft sets. For example, in OTJ, there are several payoffs for controlling a creature with power 4 or greater. In TDM, there were payoffs for beholding a dragon. Here, those would likely be clumped into the same theme. 

Figuring out the themes themselves is the difficult (and interesting) part of designing the cube! Once the themes are set, other pieces can start falling into place. 

## Pairs vs Triads

Typical draft environments have ten two-color themes, one per color pair (eg UR Spellslinger). That is certainly an option here. 

Two-color themes may become repetitive. The card pool in a cube is mostly fixed, and uncommons in general can push themes pretty hard. Every UR deck could ends up being the same pile of cards that say `whenever you cast...`. 

This is not proven. Honestly, we don't play that often. We might get enough variety from regular updates as new sets are released. 

Three-color themes are the other option. One per shard (eg UBR Discard), one per wedge (eg GUR Multicolor). With overlapping three-color themes, a given UR deck can pull from any combination of URW, UBR, and/or GUR themes. 

Notably: three-color themes only add variety if people are playing two-color decks! This means we probably want the fixing to be pretty modest. Probably comparable to BLB or ONE; these are recent sets where decks typically did not play a third color. 

## Potential Themes

Here are some themes that have showed up in recent sets. This is a starting point, not an exhaustive list. 

- Lifegain
- Discarding cards -- madness, mayhem, [[Marauding Mako]]
- Multicolor -- converge, domain, vivid
- Artifacts -- affinity, metalcraft
- Goblins or some other kindred type that uses 1/1 tokens
- Zombies or some other kindred type that uses 2/2 tokens
- Spirits or some other kindred type that uses 1/1 flying tokens
- Fatties -- dinosaurs, dragons, power matters
- Aristocrats -- sacrifice, drain, bringing back multiple small creatures
- ETB value -- blink and/or recursion
- Attacking -- raid, morbid, bloodthirst
- Tap/untap -- convoke, saddle, web-slinging, survival
- Spellslinger -- double spell, prowess, heroic, repartee, crimes
- Drawing extra cards
- Legendary/historic
- Ramp -- landfall, mana value matters
- +1/+1 Counters -- I don't love this one, honestly, since counters are a common bookkeeping tool across all colors. But there is plenty of support if we need it
- Graveyard. Wary of this one since I think it's tedious if players have to babysit each others' graveyards

Be careful not to mix conflicting sub-themes. For example, BG Forage (which wants to eat the graveyard) would not fit under the same umbrella as RG Delirium (which wants to make the graveyard big). 

## Proof of Concept

We'll mock up proofs of concept while considering different possible themes. 

For a two-color theme that means:
- Four payoffs per color
- Four enablers per color
- Three on-theme multicolored cards (payoffs and/or enablers)

For a three-color theme that means:
- Three payoffs per color
- Three enablers per color
- Three on-theme multicolor cards, one per color pair (eg UBR -> UB, BR, UR)

Payoffs should generally *not* overlap between themes. The payoffs should also be *pretty strong*. We want players to take these cards early and draft their deck around them. I expect a decent number of payoffs in the cube to be rares rather than uncommons.

Avoid bombs which incidentally support a theme but in practice dominate a game on their own (eg [[Nova Hellkite]] does not care about dragon kindred synergies). 

Mana curve matters. Avoid logjams where most of the cards have the same mana value. 

## Respect the Card Pool

We can, without too much trouble, assemble a BRG Go-Wide theme. We can also easily assemble a +1/+1 Counters theme in BGU. However, if we do, we'll have trouble finding things to do with W. A large portion of the W cards we would play, especially at high mana value, are about +1/+1 counters and/or 1/1 tokens!

## Off-Color Bleed

The cube should never include a powerful off-color payoff for any theme. For example, if we have UR Spellslinger (or URW Spellslinger) we should not include [[Dragonsguard Elite]] in the cube. This card would be a recipe for confusion and frustration during the draft! 

Off-color enablers are acceptable (and inevitable). For example, if we have WUB Artifacts, it's still ok to include a few artifact creatures in R and G. Just make sure the number is small compared to W, U, and B. 

Card choices can often be tweaked to reduce bleed. For example, we expect to have some B cards which return creatures from the graveyard. If ETB Value is on-theme for B, we might include [[Graveshifter]]. If not, we might instead play [[Gathering of Darkness]] in that slot.
